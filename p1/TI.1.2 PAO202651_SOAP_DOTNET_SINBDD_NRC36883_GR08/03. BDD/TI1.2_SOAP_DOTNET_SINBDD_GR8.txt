Buen día, Ingeniero.

El proyecto fue desarrollado bajo el requerimiento SIN BASE DE DATOS (SIN BDD). 
El servicio no utiliza ningún motor de base de datos ni capa de persistencia: 
las credenciales, los tokens de sesión (vigentes por 30 minutos) y el historial 
compartido de conversiones (máximo 100 registros) se administran en memoria dentro 
del servidor CoreWCF, y el catálogo de unidades se define mediante enumeraciones.

Por esta razón, no se elaboró el Modelo Entidad-Relación (MER) ni el diagrama de 
clases de entidades persistentes, ya que no existen tablas ni entidades que 
almacenar. Las carpetas 02. MER y 03. BDD se mantienen únicamente para conservar 
la estructura solicitada.
