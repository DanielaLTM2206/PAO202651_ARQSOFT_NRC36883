Catálogo de Magnitudes Soportadas
Categoría Base Unidades Disponibles
Longitud metros centimetros, metros, pies, yardas, millas
Masa kilogramos gramos, kilogramos, onzas, libras, quintales
Temperatura celsius celsius, fahrenheit, kelvin, newton, reaumur
ESTRUCTURA DE RESPUESTA DEL SERVICIO:
  • 200 Éxito en la operación
  • AUTH-001 Token inválido o sesión expirada
  • UNIT-001 Unidad no soportada en el catálogo
  • PARAM-001 Inconsistencia de magnitudes o valor nulo
Ejemplo de Petición y Respuesta del Servicio 
<!-- SOAP Request: convertir -->
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/" xmlns:ser="http://monster.edu.ec/services">
   <soapenv:Header/>
   <soapenv:Body>
      <ser:convertir>
         <valor>100.0</valor>
         <unidadOrigen>metros</unidadOrigen>
         <unidadDestino>pies</unidadDestino>
         <token>b811ad30-8452-4467-bc8a-7c98031a04ec</token>
      </ser:convertir>
   </soapenv:Body>
</soapenv:Envelope>

<!-- SOAP Response: RespuestaConversion -->
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/">
   <soapenv:Body>
      <ns2:convertirResponse xmlns:ns2="http://monster.edu.ec/services">
         <return>
            <estado>OK</estado>
            <codigo>200</codigo>
            <mensaje>Conversión realizada exitosamente</mensaje>
            <resultado>328.0839895013123</resultado>
            <categoria>Longitud</categoria>
            <unidadOrigen>metros</unidadOrigen>
            <unidadDestino>pies</unidadDestino>
            <valorOriginal>100.0</valorOriginal>
         </return>
      </ns2:convertirResponse>
   </soapenv:Body>
</soapenv:Envelope>
